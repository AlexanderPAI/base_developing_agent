# Base Developing Agent

Простой учебный coding-агент на Python. Агент отправляет задачу языковой модели через OpenRouter, позволяет модели выполнять команды в `bash` и возвращает итоговый ответ пользователю.

Проект создан по мотивам [видео Алексея Голобурдина](https://www.youtube.com/watch?v=H7FSTj4x4xQ&t=53s).

## Как это работает

Агент выполняет цикл из трёх шагов:

1. Отправляет модели историю диалога и описание доступного инструмента.
2. Если модель запросила команду `bash`, выполняет её и добавляет результат в историю.
3. Когда модель возвращает обычный текст без вызова инструмента, завершает работу.

Упрощённо цикл выглядит так:

```python
while True:
    response = call_llm(messages)
    if response.tool_calls:
        messages.append(execute_tools(response.tool_calls))
    else:
        return response
```

## Установка

Для запуска нужны Python 3.15+, [uv](https://docs.astral.sh/uv/) и ключ OpenRouter.

```bash
uv sync
```

Создайте файл `.env` в корне проекта:

```dotenv
LLM_API_KEY=ваш_ключ_openrouter
LLM_MODEL=идентификатор_модели
```

## Запуск

```bash
uv run python -m main "Что ты умеешь?"
```

Агент может читать и изменять файлы, запускать программы и выполнять другие команды оболочки в текущем окружении.

> [!WARNING]
> Инструмент `bash` запускает команды через `shell=True` без песочницы. Используйте проект только в доверенном или изолированном окружении.
