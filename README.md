# Base Developing Agent

Простой учебный coding-агент на Python. Агент отправляет задачу языковой модели через OpenRouter, позволяет модели выполнять команды оболочки и возвращает итоговый ответ пользователю.

Проект создан по мотивам [видео Алексея Голобурдина](https://www.youtube.com/watch?v=H7FSTj4x4xQ&t=53s).

## Как это работает

Основной цикл инкапсулирован в классе `AgentCore` и выполняет три шага:

1. Отправляет модели историю диалога и описание доступного инструмента.
2. Если модель запросила инструмент `bash`, выполняет команду и добавляет результат в историю.
3. Когда модель возвращает обычный текст без вызова инструмента, завершает работу. Если этого не произошло за заданное число итераций, агент останавливается принудительно.

Упрощённо цикл выглядит так:

```python
while True:
    content, tool_calls = agent.call_llm(messages)
    if tool_calls:
        for tool_call in tool_calls:
            result = agent.call_tool(
                tool_call.function.name,
                json.loads(tool_call.function.arguments),
            )
            messages.append(result)
    else:
        return content
```

Перед началом работы агент дополняет системный промпт сведениями об операционной системе, используемой оболочке, текущей рабочей директории и каталоге для временных файлов. Команды запускаются независимо: смена директории в одном вызове не сохраняется для следующего. Вывод команд декодируется с учётом кодировки консоли Windows.

## Структура проекта

- `src/app.py` — точка входа и обработка аргументов командной строки;
- `src/agent_core.py` — взаимодействие с LLM, вызов инструментов и управление циклом агента;
- `src/config.py` — загрузка настроек из переменных окружения и `.env`;
- `src/system_prompt.py` — системный промпт и описание доступного LLM инструмента;
- `src/tools.py` — реализация командного инструмента и реестр инструментов.

## Установка

Для запуска нужны Python 3.15+, [uv](https://docs.astral.sh/uv/) и ключ OpenRouter.

```bash
uv sync
```

Создайте файл `.env` в корне проекта:

```dotenv
LLM_API_KEY=ваш_ключ_openrouter
LLM_MODEL=идентификатор_модели
MAX_TURNS=100
```

`MAX_TURNS` необязателен; по умолчанию агент выполняет не более 100 итераций.

## Запуск

```bash
uv run python -m src.app "Что ты умеешь?"
```

Задача собирается из всех аргументов после имени модуля. Если запустить приложение без задачи, оно завершится с ошибкой.

Агент может читать и изменять файлы, запускать программы и выполнять другие команды оболочки в текущем окружении. Команды ограничены тайм-аутом в 120 секунд, а весь цикл — значением `MAX_TURNS`.

> [!WARNING]
> Инструмент `bash` запускает команды через `shell=True` без песочницы. На Unix используется `/bin/sh`, на Windows — системная командная оболочка. Используйте проект только в доверенном или изолированном окружении.
